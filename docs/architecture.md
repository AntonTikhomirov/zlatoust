# Архитектура и решения

## Схема

```
Окно приложения (pywebview + WebView2, иконка assets/icon.ico)
   │  React + TypeScript, запись через MediaRecorder (webm VP8/Opus)
   ▼
Ядро на Python (FastAPI, 127.0.0.1:8765)  ── SQLite + папка записей
   │  очередь анализа: одна запись за раз
   ▼
Конвейер: PyAV (звук, кадры) → faster-whisper (слова с метками времени)
          → метрики речи (темп, паузы, паразиты, повторы)
          → Praat/parselmouth (тон, громкость, затухание фраз)
          → сравнение с эталоном (дикция, WER/CER)
          → MediaPipe Pose + Face (взгляд, мимика, осанка, жесты, кадр)
          → оценки 0–100 и наблюдения (код)
          → толкование: правила / Ollama / Claude API (строгий JSON)
```

## Ключевые решения

1. **Оценки считает код, LLM только объясняет.** Цифры воспроизводимы, LLM не может «нафантазировать» оценку. Ответ LLM проверяется по JSON-схеме; при любой ошибке — разбор по правилам.
2. **Своё окно приложения (pywebview поверх WebView2), без браузера.** Окно сразу показывает заставку «Запускаю…», ядро стартует в том же процессе, интерфейс загружается, только когда ядро ответило. Закрыли окно — процесс завершается (дождавшись начатого анализа). Камера и микрофон разрешаются своему интерфейсу автоматически. Первая версия открывалась через Edge `--app` и сломалась: Edge при первом запуске перезапускает сам себя, и приложение принимало это за закрытие окна.
3. **Зависимости строго по `uv.lock`,** Python ставит сам `uv`. Никаких системных ffmpeg и CUDA Toolkit: ffmpeg внутри PyAV, библиотеки CUDA — pip-пакеты `nvidia-cublas-cu12` и `nvidia-cudnn-cu12`. cuBLAS закреплён на 12.6, потому что в новых версиях нет сборок под Windows.
4. **Распознавание:** large-v3 на видеокарте (float16, затем int8_float16), при любой ошибке CUDA — small на процессоре. Подсказка `initial_prompt` с «ну, э-э, вот», иначе Whisper вычищает паразиты из текста.
5. **Темп в слогах в секунду** (в русском слог = гласная), а не в словах: слова разной длины, слоги честнее.
6. **Обработка звука в браузере выключена** (шумодав, автоусиление, эхоподавление), иначе искажаются громкость и паузы.
7. **Видео анализируется на 10 кадрах в секунду,** движение рук считается относительно плеч, чтобы покачивание корпуса не засчитывалось как жест.

## Пороги (стартовые, будут калиброваться)

| Навык | Норма | Где |
|---|---|---|
| Темп | 3,4–5,2 слога/с | `analysis/scoring.py` |
| Паузы | 10–30% времени речи, без пауз > 2 с | там же |
| Паразиты | до 1,5 в минуту | там же |
| Интонация | разброс тона ≥ 2,5 полутона | там же |
| Громкость | концы фраз тише середины не более чем на 6 дБ; уровень микрофона оценку не снижает, только предупреждение ниже −45 дБ | там же |
| Взгляд | ≥ 70% времени в камеру | там же |
| Жесты | активны 12–50% времени | там же |

## Известные ограничения

- Whisper склонен «исправлять» нечёткие слова по смыслу, поэтому дикция по распознаванию — приближение. Неуверенные слова подчёркнуты в расшифровке.
- Взгляд определяется по повороту головы и положению зрачков. Если камера сильно выше экрана, взгляд на экран засчитывается как «вниз».
- Программы тренировок по результатам диагностики пока нет: следующее упражнение выбирается под самый слабый навык.
